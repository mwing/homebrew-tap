# homebrew-tap

Homebrew formulae for [isolated-dev](https://github.com/mwing/isolated-dev).

```sh
brew tap mwing/tap
brew install dev
```

`dev` runs code in a container without learning Docker, in a sandbox that is
closed by default and opened one deliberate step at a time.

The formula here is written by [goreleaser](https://goreleaser.com) when a
version is tagged in the main repository. Edit it there, not here.
